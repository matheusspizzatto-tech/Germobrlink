Perguntas

Dúvidas de quem é da área.

Preciso ter um sistema de gestão do leite?+

Não. Você manda os números por áudio ou mensagem e a planilha é montada para você. Se já tem uma planilha, é só mandar que nós continuamos a partir dela.

Serve para quem tem poucas vacas?+

Sim. Funciona do mesmo jeito para 10 ou para 300 vacas. Você paga pelo plano, não pelo tamanho do rebanho.

O ajudante substitui o veterinário?+

Não. Ele organiza os dados e avisa quando algo foge do normal, como uma queda de produção. Diagnóstico e tratamento são sempre com o seu veterinário.
